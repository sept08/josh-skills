# Josh-Skills

这是一个个人使用的 Claude Code skills 集合仓库。

## 安装方式

### 快速安装

在 Claude Code 中执行：

```bash
npx skills add sept08/josh-skills
```

### 注册为插件市场

在 Claude Code 中执行：

```bash
/plugin marketplace add sept08/josh-skills
```

### 直接安装

```bash
/plugin install josh-skills@josh-skills
```

### 让 Agent 安装

直接告诉 Claude Code：

> Please install Skills from github.com/sept08/josh-skills
